Please update the user-facing `:debug-log-capacity` command so it can be used to request an unlimited in-memory log capacity with `-1`. Right now the command rejects all negative values, which makes the unlimited mode inaccessible. After this change, `:debug-log-capacity -1` should be accepted and switch the RAM log buffer to unlimited capacity, while other negative values should still be rejected with a clear error instead of being treated as valid.
